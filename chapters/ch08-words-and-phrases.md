# Chapter 8: စကားလုံး၊ ပုဒ်နှင့် ပုဒ်စု (Words, Stems, and Phrases)

## Core Idea
ဘာသာစကားတစ်ခု၏ အနက်သဘော ဆောင်သော အခြေခံအဆောက်အအုံသည် စကားလုံး (Word) ဖြစ်ပြီး၊ ဝါကျအတွင်း အခန်းကဏ္ဍတစ်ခုအနေဖြင့် ပါဝင်လာသောအခါ ပုဒ် (Syntactic Word/Stem) ဖြစ်လာကာ၊ ပုဒ်များ ပေါင်းစပ်ဖွဲ့စည်းမှုမှတစ်ဆင့် ပုဒ်စု (Phrase) ဖြစ်ပေါ်လာသည်။

## Frameworks Introduced
- **စကားလုံး ၂ မျိုး ခွဲခြားမှု မူဘောင်**:
  1. **အနက်ဆောင်စကားလုံး (Content Words)**: မိမိဘာသာ သီးခြား အနက်အဓိပ္ပာယ် အပြည့်အဝရှိသော စကားလုံးများ (လူ၊ ကျောင်း၊ သွား၊ လှ၊ မြန်)။
  2. **အနက်ထောက်စကားလုံး (Function/Grammatical Words)**: သီးခြားအနက်မရှိဘဲ အခြားစကားလုံးများနှင့် တွဲဖက်မှ သဒ္ဒါအနက်ကို ထောက်ကူပေးသော စကားလုံးများ (သည်၊ ကို၊ ၏၊ သော၊ ၍)။
- **စကားလုံး -> ပုဒ် -> ပုဒ်စု အဆင့်ဆင့် ဖွံ့ဖြိုးမှု မူဘောင်**:
  - စကားလုံး (သီးခြားတည်ရှိမှု) -> ပုဒ် (ဝါကျတွင်း တာဝန်ယူမှု) -> ပုဒ်စု (ပုဒ်နှစ်ခု သို့မဟုတ် နှစ်ခုထက်ပို၍ အနက်တစ်ခုတည်းအဖြစ် ပေါင်းစပ်မှု)။

## Key Concepts
- **စကားလုံး (Word)**: အဓိပ္ပာယ်သဘောကို ဖော်ပြနိုင်သော အခြေခံ စကားအသံ။
- **ပုဒ် (Syntactic Term)**: ဝါကျတစ်ခုတွင် ဝါစင်္ဂတစ်ခုခုအဖြစ် တာဝန်ယူ ပါဝင်ဆောင်ရွက်သော စကားလုံး။
- **ပုဒ်စု (Phrase)**: ပုဒ်နှစ်ခု သို့မဟုတ် နှစ်ခုထက်ပို၍ စုပေါင်းကာ ဝါကျတွင်း၌ ဝါစင်္ဂတစ်ခုကဲ့သို့ ဆောင်ရွက်သော အစု (ဥပမာ- "စာအုပ်ကြီး"၊ "အလွန်မြန်စွာ")။

## Mental Models
- **အုတ်ချပ်မှ အဆောက်အအုံသို့ မော်ဒယ်**: စကားလုံးများသည် အုတ်ချပ်များဖြစ်ပြီး၊ ဘိလပ်မြေ (အနက်ထောက်စကားလုံး/ဝိဘတ်) ဖြင့် တွဲစပ်လိုက်သောအခါ နံရံ (ပုဒ်စု) နှင့် အိမ်ကြီး (ဝါကျ) အဖြစ် ဖွဲ့စည်းတည်ဆောက်နိုင်ကြသည်။

## Anti-patterns
- **စကားလုံးနှင့် ပုဒ်ကို မခွဲခြားနိုင်ခြင်း**: အဘိဓာန်ထဲတွင် သီးခြားရှိနေချိန်၌ စကားလုံးဖြစ်ပြီး၊ ဝါကျထဲသို့ ရောက်ရှိသွားသောအခါမှသာ သဒ္ဒါအရ 'ပုဒ်' ဖြစ်လာသည်ကို သတိမပြုမိခြင်း။
- **ပုဒ်စုကို ဝါကျအပြည့်အစုံဟု ထင်မှတ်ခြင်း**: ပုဒ်စုတွင် ကတ္တားနှင့် အဆုံးသတ်ကြိယာ ပြည့်စုံစွာ မပါဝင်နိုင်ဘဲ ဝါကျ၏ အစိတ်အပိုင်းတစ်ခုသာ ဖြစ်ကြောင်း မေ့လျော့ခြင်း။

## Worked Example
- အဆင့်ဆင့် ခွဲခြမ်းစိတ်ဖြာမှု:
  - "စာအုပ်" -> နာမ်စကားလုံး။
  - "အနီရောင် စာအုပ်ကြီး" -> ပုဒ်စု (နာမ်ပုဒ်စု ဖြစ်သည်)။
  - "မောင်မောင်သည် အနီရောင် စာအုပ်ကြီးကို ဖတ်သည်" -> ပုဒ်များနှင့် ပုဒ်စုများ ပေါင်းစပ်ထားသော ဝါကျ။

## Key Takeaways
1. စကားလုံးတွင် အနက်ဆောင်စကားလုံးနှင့် အနက်ထောက်စကားလုံးဟူ၍ ရှိသည်။
2. ဝါကျအတွင်း ပါဝင်လာသော စကားလုံးကို ပုဒ်ဟု ခေါ်သည်။
3. ပုဒ်များ အနက်သဘောအရ စုစည်းမိသောအခါ ပုဒ်စု (Phrase) ဖြစ်လာသည်။
