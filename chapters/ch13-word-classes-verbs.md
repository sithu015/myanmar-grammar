# Chapter 13: ဝါစင်္ဂ - ကြိယာနှင့် ကာလ (Word Classes: Verbs and Tenses)

## Core Idea
ကြိယာဆိုသည်မှာ ဝါကျအတွင်း ကတ္တား၏ ပြုလုပ်ခြင်း၊ ဖြစ်ပျက်ခြင်း သို့မဟုတ် တည်ရှိနေခြင်းကို ဖော်ပြသော အဓိကမဏ္ဍိုင် ဝါစင်္ဂဖြစ်ပြီး၊ အတိတ်၊ ပစ္စုပ္ပန်၊ အနာဂတ် ဟူသော ကာလ ၃ ပါးနှင့် ဆက်စပ်တည်ဆောက်သည်။

## Frameworks Introduced
- **ကြိယာ အမျိုးအစား မူဘောင် (Verb Types Framework)**:
  1. **ကံလိုကြိယာ (Transitive Verb)**: အနက်ပြည့်စုံရန် ကံပုဒ် (Object) လိုအပ်သော ကြိယာ (ဥပမာ- စားသည်၊ ရိုက်သည်၊ ဖတ်သည် - ဘာကိုစား/ဖတ်သနည်း ဟူသော ကံ လိုအပ်သည်)။
  2. **ကံမလိုကြိယာ (Intransitive Verb)**: ကံပုဒ်မပါဘဲ အနက်ပြည့်စုံသော ကြိယာ (ဥပမာ- အိပ်သည်၊ ငိုသည်၊ သွားသည်၊ ဝသည်)။
  3. **ပြည့်စုံကြိယာနှင့် မပြည့်စုံကြိယာ**:
     - ပြည့်စုံကြိယာ - သီးခြားရပ်တည်နိုင်သော ပင်မကြိယာ။
     - မပြည့်စုံ/ထောက်ပံ့ကြိယာ (Auxiliary Verb) - ပင်မကြိယာကို ကူညီထောက်ပံ့ပေးသော စကားလုံးများ (ဥပမာ- 'ချင်'သည်၊ 'နိုင်'သည်၊ 'စကောင်း'သည်)။
- **ကာလ ၃ ပါး မူဘောင် (Tense Framework)**:
  1. **အတိတ်ကာလ (Past Tense)**: ပြီးမြောက်ခဲ့သောအမှု (ဥပမာ- သွား'ခဲ့'သည်၊ စား'ပြီး'ပြီ)။
  2. **ပစ္စုပ္ပန်ကာလ (Present Tense)**: ယခုမျက်မှောက် ဖြစ်ဆဲအမှု (ဥပမာ- သွား'သည်'၊ ဖတ်'နေ'သည်)။
  3. **အနာဂတ်ကာလ (Future Tense)**: နောင်တွင် ဖြစ်လတ္တံ့သောအမှု (ဥပမာ- သွား'မည်'၊ ဖတ်'အံ့'၊ လာ'လိမ့်မည်')။

## Key Concepts
- **ကြိယာ (Verb)**: ပြုလုပ်ခြင်း၊ ဖြစ်ခြင်းကို ပြသော စကားလုံး။
- **ကံ (Object)**: ကြိယာ၏ ပြုလုပ်ခြင်းဒဏ်ကို ခံရသော နာမ်ပုဒ်။
- **ကာလပြပစ္စည်း/ဝိဘတ်**: ကြိယာအဆုံးတွင် ကာလကို ခွဲခြားပေးသော သင်္ကေတများ (ခဲ့၊ သည်၊ မည်)။

## Mental Models
- **အင်ဂျင်စက် မော်ဒယ် (The Engine Model)**: နာမ်များသည် ဝါကျ၏ ကိုယ်ထည်ဖြစ်ပါက၊ ကြိယာသည် ထိုကိုယ်ထည်ကို လှုပ်ရှားလည်ပတ်စေသော အင်ဂျင်စက်ခေါင်းကြီး ဖြစ်သည်။ ကြိယာမပါလျှင် ဝါကျသည် အသက်မဝင်နိုင်ချေ။

## Anti-patterns
- **ကံလိုကြိယာတွင် ကံပုဒ်ချန်လှပ်၍ အဓိပ္ပာယ်မပြည့်စုံခြင်း**: "သူသည် ခုတ်သည်" ဟု ရေးသားရာတွင် အဘယ်အရာကို ခုတ်သည်ဟူသော ကံပုဒ် (ဥပမာ- ထင်းကို) မပါလျှင် အနက်မပြည့်စုံနိုင်ချေ။
- **ကာလပြဝိဘတ်များကို ရောထွေးသုံးစွဲခြင်း**: အတိတ်ဖြစ်ရပ်ကို ရေးသားရာတွင် အနာဂတ်ပြဝိဘတ် (မည်) နှင့် ရောထွေးသုံးစွဲခြင်း။

## Worked Example
- ကြိယာခွဲခြမ်းစိတ်ဖြာမှု:
  - "မောင်မောင်သည် စာအုပ်ကို **ဖတ်ခဲ့သည်**။"
    - 'ဖတ်' = ကံလိုကြိယာ (စာအုပ် ဟူသော ကံ လိုအပ်သည်)။
    - 'ခဲ့' = အတိတ်ကာလပြ အထောက်အကူ။
    - 'သည်' = ကြိယာဝိဘတ်။
  - "ကလေးသည် **အိပ်ပျော်နေသည်**။"
    - 'အိပ်ပျော်' = ကံမလိုကြိယာ။
    - 'နေသည်' = ပစ္စုပ္ပန်ကာလ အခြေအနေပြ။

## Key Takeaways
1. ကြိယာသည် ပြုမူခြင်း၊ ဖြစ်ပျက်ခြင်းကို ပြသော ဝါကျ၏ အဓိကကျောရိုး ဖြစ်သည်။
2. ကံလိုကြိယာနှင့် ကံမလိုကြိယာဟူ၍ အဓိက ၂ မျိုး ခွဲသည်။
3. အတိတ် (ခဲ့)၊ ပစ္စုပ္ပန် (သည်/နေသည်)၊ အနာဂတ် (မည်) ဟူသော ကာလ ၃ ပါးဖြင့် အချိန်ကာလကို သတ်မှတ်သည်။
