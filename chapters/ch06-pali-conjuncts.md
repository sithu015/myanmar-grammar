# Chapter 6: ပါဠိဆင့်ရေးနည်းနှင့် ဖတ်နည်း (Pali Orthography and Conjuncts)

## Core Idea
ပါဠိဘာသာမှ ဆင်းသက်လာသော စကားလုံးများတွင် ဗျည်းနှစ်လုံး တစ်ခုပေါ်တစ်ခု ထပ်ဆင့်ရေးသားရာ၌ ဝဂ်အလိုက် သတ်မှတ်ထားသော ဗျည်းဆင့်စည်းမျဉ်းများနှင့် တိကျသောအသံထွက် နည်းစနစ်များ ရှိသည်။

## Frameworks Introduced
- **ဝဂ်ဗျည်းဆင့် စည်းမျဉ်း ၃ ရပ် (Wag Conjunct Rules)**:
  1. **စည်းမျဉ်း ၁ (၁-၂ ဆင့်နည်း)**: ဝဂ်တစ်ခု၏ ပထမဗျည်းအောက်တွင် ထိုဝဂ်၏ ပထမ သို့မဟုတ် ဒုတိယဗျည်းသာ ဆင့်နိုင်သည် (ဥပမာ- က္က၊ က္ခ၊ စ္စ၊ စ္ဆ၊ ဋ္ဋ၊ ဋ္ဌ၊ တ္တ၊ တ္ထ၊ ပ္ပ၊ ပ္ဖ)။
  2. **စည်းမျဉ်း ၂ (၃-၄ ဆင့်နည်း)**: ဝဂ်တစ်ခု၏ တတိယဗျည်းအောက်တွင် ထိုဝဂ်၏ တတိယ သို့မဟုတ် စတုတ္ထဗျည်းသာ ဆင့်နိုင်သည် (ဥပမာ- ဂ္ဂ၊ ဂ္ဃ၊ ဇ္ဇ၊ ဇ္ဈ၊ ဍ္ဍ၊ ဍ္ဎ၊ ဒ္ဒ၊ ဒ္ဓ၊ ဗ္ဗ၊ ဗ္ဘ)။
  3. **စည်းမျဉ်း ၃ (၅-အားလုံး ဆင့်နည်း)**: ဝဂ်တစ်ခု၏ ပဉ္စမဗျည်း (နှာသံ) အောက်တွင် ထိုဝဂ်၏ ဗျည်း ၅ လုံးစလုံး ဆင့်နိုင်သည် (ဥပမာ- င်္က၊ င်္ခ၊ င်္ဂ၊ င်္ဃ၊ င်္င / ဉ္စ၊ ဉ္ဆ၊ ဉ္ဇ၊ ဉ္ဈ၊ ဉ္ည / ဏ္ဋ၊ ဏ္ဌ၊ ဏ္ဍ၊ ဏ္ဎ၊ ဏ္ဏ / န္တ၊ န္ထ၊ န္ဒ၊ န္ဓ၊ န္န / မ္ပ၊ မ္ဖ၊ မ္ဗ၊ မ္ဘ၊ မ္မ)။
- **အဝဂ်ဗျည်းဆင့် စည်းမျဉ်း**:
  - အဝဂ်ဗျည်းများတွင် ယျ၊ လ္လ၊ သ္သ ဟူ၍ တူရာဗျည်းအချင်းချင်း ဆင့်နိုင်သည် (ဥပမာ- အာယုဝဍ္ဎန၊ ကလျာ၊ သဿမေဓ)။

## Key Concepts
- **ဗျည်းဆင့် (Conjunct)**: အထက်ဗျည်း၌ အသတ်သံထွက်ပြီး အောက်ဗျည်း၌ မူလသရသံထွက်သော ပေါင်းစပ်ရေးထုံး။
- **အထက်ဗျည်း**: အသတ်သဘောဆောင်သောအက္ခရာ (သံပြတ်)။
- **အောက်ဗျည်း**: သရသံအပြည့် ထွက်ရသောအက္ခရာ။

## Mental Models
- **ဝဂ်အိမ် မော်ဒယ် (Varga Household Model)**: ဝဂ်တစ်ခုစီသည် အိမ်ထောင်စုတစ်ခုဖြစ်ပြီး ၁ နှင့် ၂၊ ၃ နှင့် ၄ အချင်းချင်းသာ တွဲဖက်နိုင်ကာ ၅ (နှာသံအကြီးအကဲ) သည် မိမိအိမ်သား အားလုံးနှင့် တွဲဖက်ခွင့်ရှိသည်။ အခြားဝဂ်အိမ်သားများနှင့် ကူးလူးဆင့်ပွားခွင့် မရှိချေ။

## Anti-patterns
- **ဝဂ်ကျော်၍ ဗျည်းဆင့်ခြင်း**: ကဝဂ်ဗျည်းအောက်တွင် စဝဂ်ဗျည်းသွားဆင့်ခြင်း (ဥပမာ- 'က္စ' ကဲ့သို့ ရေးထုံးမျိုး မရှိပါ)။
- **အသံထွက်ရာတွင် အထက်ဗျည်းအသံကို ချန်လှပ်ခြင်း**: "သစ္စာ" ကို [သ-စာ] ဟု မဖတ်ဘဲ [သစ်-စာ] ဟု အထက်ဗျည်းကို အသတ်သံ ထည့်ဖတ်ရမည်။

## Worked Example
- ပါဠိဆင့် ခွဲခြမ်းစိတ်ဖြာမှု:
  1. **သုခ** (ကဝဂ် ၁-၂) -> ဒုက္ခ (ဒုက် + ခ) = ၁ အောက် ၂ ဆင့်။
  2. **ဗုဒ္ဓ** (တဝဂ် ၃-၄) -> ဒ အောက် ဓ ဆင့် = ၃ အောက် ၄ ဆင့် [ဗုတ်-ဓ]။
  3. **သမ္မာ** (ပဝဂ် ၅-၅) -> မ အောက် မ ဆင့် = ၅ အောက် ၅ ဆင့် [သမ်-မာ]။

## Key Takeaways
1. ပါဠိဗျည်းဆင့်သည် ၁-၂၊ ၃-၄၊ ၅-အားလုံး ဟူသော ဝဂ်စည်းမျဉ်းအတိုင်းသာ ဖြစ်တည်သည်။
2. အထက်ဗျည်းကို အသတ်သံအဖြစ် ဖတ်ရပြီး အောက်ဗျည်းကို ပုံမှန်သရသံအတိုင်း ဖတ်ရသည်။
3. ဤစည်းမျဉ်းကို နားလည်ခြင်းဖြင့် မြန်မာစာလုံးပေါင်းသတ်ပုံ အမှားကင်းစင်စေသည်။
