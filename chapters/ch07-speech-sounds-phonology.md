# Chapter 7: အသံနှင့် စကားသံဖွဲ့ထုံး (Phonology and Sound Alternation)

## Core Idea
မြန်မာဘာသာစကားတွင် စာလုံးပေါင်းသတ်ပုံအတိုင်း အသံမထွက်ဘဲ ဝေါဟာရများ ပေါင်းစပ်ဆက်စပ်သွားသည့်အခါ ရှေ့အသံ၏ အဆုံးအဖြတ်အရ နောက်အသံသည် အသံပြင်းမှ အသံပျော့သို့ သဘာဝအလျောက် ပြောင်းလဲသွားသော စကားသံပြောင်းလဲမှု (Voicing/Sound Alternation) စည်းမျဉ်းများ ရှိသည်။

## Frameworks Introduced
- **စကားသံပြောင်းလဲမှု မူဘောင် (Voicing Alternation Framework)**:
  - ရှေ့စကားလုံး၏ အဆုံးသံသည် သရသံ သို့မဟုတ် နှာသတ်သံ ဖြစ်လျှင် နောက်လိုက် သိထိလ/ဓနိတဗျည်းများသည် ဃောသသံ (အသံပျော့) သို့ ပြောင်းလဲထွက်ရသည်။
  - က / ခ -> [ဂ]
  - စ / ဆ -> [ဇ]
  - တ / ထ -> [ဒ]
  - ပ / ဖ -> [ဗ]
- **စကားသံ မပြောင်းလဲသော အခြေအနေများ**:
  - ရှေ့စကားလုံးသည် ရပ်တန့်သတ် (က်၊ စ်၊ တ်၊ ပ်) ဖြင့် အဆုံးသတ်လျှင် နောက်ဗျည်းသံ ပျော့မသွားဘဲ မူလအတိုင်း ထွက်ရသည်။

## Key Concepts
- **သံပြင်း (Voiceless/Aspirated)**: အသံအိုးမတုန်ဘဲ ထွက်သောအသံ (က၊ ခ၊ စ၊ ဆ၊ တ၊ ထ၊ ပ၊ ဖ)။
- **သံပျော့ (Voiced)**: အသံအိုးတုန်ခါမှုဖြင့် နူးညံ့စွာထွက်သောအသံ (ဂ၊ ဇ၊ ဒ၊ ဗ)။
- **စကားသံပြောင်းလဲမှု (Phonological Alternation)**: စကားလုံးများ ပေါင်းစပ်ရာတွင် သဘာဝကျကျ အသံပြေပြစ်စေရန် အသံဖလှယ်ခြင်း။

## Mental Models
- **အသံစီးဆင်းမှု လွယ်ကူစေခြင်း မော်ဒယ် (Least Effort Principle)**: သရသံ သို့မဟုတ် နှာသံသည် လေစီးဆင်းနေသဖြင့် နောက်ဆက်တွဲဗျည်းကို အသံပြင်းဖိမထွက်ဘဲ အသံပျော့ပြောင်း၍ လျှောလျှောရှူရှူ ထွက်ဆိုခြင်းသည် သဘာဝကျသော လူ့အသံထွက်ဗေဒ ဖြစ်သည်။

## Anti-patterns
- **စာလုံးပေါင်းအတိုင်း အသံထွက်ရန် ဇွတ်ကြိုးစားခြင်း**: "စာအုပ်" ကို [စာ-အုပ်] ဟု မဖတ်ဘဲ [ဇာ-အုပ်] ဟု သဘာဝကျကျ အသံထွက်ရမည်ကို စာရေးထုံးအတိုင်း [စာ-အုပ်] ဟု တင်းတင်းကျပ်ကျပ် အသံထွက်ဆိုခြင်း။
- **သတ်သံနောက်တွင် အသံပျော့ပြောင်းထွက်ဆိုခြင်း**: "သစ်ပင်" တွင် 'သစ်' သည် စသတ်သံပြတ်ဖြစ်၍ 'ပင်' ကို [ဗင်] ဟု မဖတ်ဘဲ [သစ်-ပင်] ဟု သံပြင်းအတိုင်း ဖတ်ရမည်။

## Worked Example
- စကားသံပြောင်းလဲမှု စိစစ်ချက်:
  1. ရွှေ + ကျောင်း -> [ရွှေ-ဂျောင်း] (ရှေ့ 'ရွှေ' သည် သရသံဖြစ်၍ 'က' သည် 'ဂ/ဂျ' ဖြစ်သွားသည်)။
  2. စာ + သင် + ခန်း -> [ဇာ-ဒင်-ဂန်း] (စာ -> ဇာ၊ သင် -> ဒင်၊ ခန်း -> ဂန်း အသီးသီး ပြောင်းလဲသည်)။
  3. လက် + ခေါက် -> [လက်-ခေါက်] (ရှေ့ 'လက်' သည် ကသတ်ဖြစ်၍ 'ခ' အသံ မပြောင်းပါ)။

## Key Takeaways
1. စကားသံပြောင်းလဲမှုသည် မြန်မာစကား၏ သဘာဝ အသံစီးဆင်းမှု စည်းမျဉ်းဖြစ်သည်။
2. သရနှင့် နှာသတ်နောက်တွင် က/ခ->ဂ၊ စ/ဆ->ဇ၊ တ/ထ->ဒ၊ ပ/ဖ->ဗ သို့ အသံပျော့ပြောင်းသည်။
3. ရပ်တန့်သတ်များနောက်တွင် အသံပြောင်းလဲမှု မဖြစ်ပေါ်ချေ။
