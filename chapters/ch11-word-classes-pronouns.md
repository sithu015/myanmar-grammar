# Chapter 11: ဝါစင်္ဂ - နာမ်စား (Word Classes: Pronouns)

## Core Idea
နာမ်စားဆိုသည်မှာ နာမ်တစ်ခုခုကို ထပ်ခါတလဲလဲ မသုံးလိုသောအခါ နာမ်၏ကိုယ်စား အစားထိုးသုံးစွဲသော စကားလုံးဖြစ်ပြီး၊ ပုဂ္ဂလနာမ်စား၊ အညွှန်းနာမ်စား၊ အမေးနာမ်စားနှင့် သင်္ချာနာမ်စားဟူ၍ အဓိက ခွဲခြားနိုင်သည်။

## Frameworks Introduced
- **နာမ်စား အမျိုးအစားများ မူဘောင် (Pronoun Categories Framework)**:
  1. **ပုဂ္ဂလနာမ်စား (Personal Pronouns)**:
     - ပထမပုဂ္ဂိုလ် (အပြောသူ) - ကျွန်တော်၊ ကျွန်မ၊ ငါ၊ ကျုပ်၊ အကျွန်ုပ်တို့။
     - ဒုတိယပုဂ္ဂိုလ် (အကြားသူ) - သင်၊ မင်း၊ ခင်ဗျား၊ ရှင်၊ ညည်း။
     - တတိယပုဂ္ဂိုလ် (အပြောခံ) - သူ၊ ၎င်း၊ ဤသူ၊ ထိုသူ၊ သူတို့။
  2. **အညွှန်းနာမ်စား (Demonstrative Pronouns)**: အနီးအဝေး ညွှန်ပြသော နာမ်စားများ (ဒါ၊ ဟာ၊ သည်၊ ဤအရာ၊ ထိုအရာ၊ ဟိုဟာ)။
  3. **အမေးနာမ်စား (Interrogative Pronouns)**: မေးခွန်းထုတ်ရာတွင် နာမ်အစားသုံးသော စကားလုံးများ (ဘယ်သူ၊ အဘယ်သူ၊ ဘာ၊ အဘယ်အရာ)။
  4. **သင်္ချာနာမ်စား (Numeral Pronouns)**: အရေအတွက် သို့မဟုတ် အစဉ်ကို နာမ်အစားသုံးခြင်း (ဥပမာ- "နှစ်ယောက် လာသည်" တွင် 'နှစ်ယောက်')။

## Key Concepts
- **နာမ်စား (Pronoun)**: နာမ်၏ နေရာတွင် အစားထိုးသော ဝါစင်္ဂ။
- **ပုဂ္ဂလနာမ်စား**: လူပုဂ္ဂိုလ် ၃ မျိုး (ပြောသူ၊ နားထောင်သူ၊ အပြောခံ) ကို ကိုယ်စားပြုသော နာမ်စား။
- **အညွှန်းနာမ်စား**: နေရာနှင့် အရာဝတ္ထုကို လက်ညှိုးထိုးပြသကဲ့သို့ ညွှန်းဆိုသော စကားလုံး။

## Mental Models
- **သံတမန်/ကိုယ်စားလှယ် မော်ဒယ် (The Diplomat/Proxy Model)**: နိုင်ငံတော်သမ္မတကိုယ်တိုင် နေရာတိုင်း မသွားနိုင်သဖြင့် သံအမတ်က ကိုယ်စားသွားသကဲ့သို့၊ မူလနာမ်ကို စာကြောင်းတိုင်း ထပ်မခေါ်ဘဲ နာမ်စားကို ကိုယ်စားလှယ်လွှဲ၍ အသုံးပြုသည်။

## Anti-patterns
- **အညွှန်းနာမ်စားနှင့် အညွှန်းနာမဝိသေသန ရောထွေးခြင်း**:
  - "ဒါကို ယူပါ" -> 'ဒါ' သည် သီးခြားရပ်တည်သဖြင့် **အညွှန်းနာမ်စား** ဖြစ်သည်။
  - "ဒီစာအုပ်ကို ယူပါ" -> 'ဒီ' သည် 'စာအုပ်' နာမ်ကို အထူးပြုသဖြင့် **အညွှန်းနာမဝိသေသန** ဖြစ်သည်။
- **ယဉ်ကျေးမှုအဆင့်အတန်းနှင့် မကိုက်ညီသော နာမ်စားသုံးခြင်း**: မြန်မာစကားတွင် ပြောသူနှင့် နားထောင်သူ၏ ဂုဏ်သိက္ခာ၊ ရင်းနှီးမှုအလိုက် နာမ်စားရွေးချယ်မှု မှန်ကန်ရန် လိုအပ်သည်။

## Worked Example
- နာမ်စား ခွဲခြမ်းစိတ်ဖြာမှု:
  - "မောင်မောင်သည် ကျောင်းသို့ သွားသည်။ **သူသည်** စာကြိုးစားသည်။" -> 'သူ' သည် မောင်မောင်ကို အစားထိုးသော တတိယပုဂ္ဂလနာမ်စား ဖြစ်သည်။
  - "**ဘယ်သူ** လာသလဲ။" -> 'ဘယ်သူ' သည် လာရောက်သူ နာမ်ကို မေးမြန်းသော အမေးနာမ်စား ဖြစ်သည်။
  - "**ဒါသည်** ငါ့အိမ် ဖြစ်သည်။" -> 'ဒါ' သည် အနီးပြ အညွှန်းနာမ်စား ဖြစ်သည်။

## Key Takeaways
1. နာမ်စားသည် နာမ်ကို ထပ်ခါတလဲလဲ မဖြစ်စေရန် အစားထိုးသုံးစွဲသည်။
2. ပုဂ္ဂလနာမ်စား ၃ မျိုး (ပထမ၊ ဒုတိယ၊ တတိယ) ရှိသည်။
3. နာမ်ရှေ့မှ အထူးပြုနေလျှင် နာမဝိသေသနဖြစ်ပြီး၊ သီးခြားရပ်တည်မှသာ နာမ်စား ဖြစ်သည်။
