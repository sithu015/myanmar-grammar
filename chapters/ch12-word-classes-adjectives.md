# Chapter 12: ဝါစင်္ဂ - နာမဝိသေသန (Word Classes: Adjectives)

## Core Idea
နာမဝိသေသနဆိုသည်မှာ နာမ် သို့မဟုတ် နာမ်စား၏ ဂုဏ်အရည်အချင်း၊ ပုံသဏ္ဌာန်၊ အရေအတွက်၊ အတိုင်းအတာနှင့် အခြေအနေတို့ကို ပိုမိုထင်ရှားပေါ်လွင်အောင် အထူးပြုဖော်ပြသော စကားလုံး ဖြစ်သည်။

## Frameworks Introduced
- **နာမဝိသေသန အမျိုးအစားများ မူဘောင် (Adjective Classification Framework)**:
  1. **ပင်ကိုနာမဝိသေသန (Quality Adjectives)**: မူလအရည်အသွေးကို ပြသောအရာ (ဥပမာ- လူ'ကောင်း'၊ မြင်း'ဖြူ'၊ သစ်ပင်'ကြီး'၊ ပန်း'လှ')။
  2. **အညွှန်းနာမဝိသေသန (Demonstrative Adjectives)**: နာမ်ကို ညွှန်ပြသောအရာ (ဥပမာ- 'ဤ'လူ၊ 'ထို'အကြောင်း၊ 'သည်'စာအုပ်)။
  3. **သင်္ချာနာမဝိသေသန (Numeral Adjectives)**: အရေအတွက် သို့မဟုတ် အစဉ်ကို ပြသောအရာ (ဥပမာ- လူ'တစ်ဆယ်'၊ 'ပထမ'ဆု)။
  4. **အမေးနာမဝိသေသန (Interrogative Adjectives)**: နာမ်နှင့်တွဲ၍ မေးမြန်းသောအရာ (ဥပမာ- 'မည်သည့်'အရာ၊ 'အဘယ်'အကြောင်း)။
- **နာမဝိသေသန အဆင့်ခွဲခြားမှု မူဘောင် (Degrees of Comparison)**:
  - **သာမန်အဆင့်**: ပုံမှန်ဂုဏ်အရည်အသွေး (ဥပမာ- ကြီးသော)။
  - **သာလွန်အဆင့်**: အခြားတစ်ခုထက် သာလွန်ကြောင်းပြ (ဥပမာ- ပိုကြီးသော၊ ကြီးသောအရာ)။
  - **အသာလွန်ဆုံးအဆင့်**: အားလုံးထဲတွင် အမြင့်ဆုံးပြ (ဥပမာ- အကြီးဆုံး၊ အကောင်းဆုံး)။

## Key Concepts
- **နာမဝိသေသန**: နာမ်ကို အထူးပြုသော ဝါစင်္ဂ။
- **အထူးပြုခံ (Head Noun)**: နာမဝိသေသန၏ အထူးပြုခြင်းကို ခံရသော မူလနာမ်။
- **အဆင့်ခွဲပစ္စည်း**: အသာလွန်ဆုံးကို ဖော်ပြသော 'အ-ဆုံး' ပစ္စည်း (ဥပမာ- အတော်ဆုံး၊ အလှဆုံး)။

## Mental Models
- **အရောင်တင်ဆီ မော်ဒယ် (The Varnish/Detailing Model)**: နာမ်သည် ပရိဘောဂသစ်သားဖြစ်ပါက၊ နာမဝိသေသနသည် ထိုသစ်သား၏ အရောင်၊ အသွေး၊ အရွယ်အစားကို ပေါ်လွင်စေသော အရောင်တင်ဆီနှင့် ထွင်းထုမှု ဖြစ်သည်။

## Anti-patterns
- **ကြိယာနှင့် နာမဝိသေသန နေရာလွဲမှားခြင်း**:
  - "ပန်းသည် **လှသည်**" -> ဤနေရာတွင် 'လှသည်' သည် ဝါကျ၏ အဆုံးသတ် **ကြိယာ** ဖြစ်သည်။
  - "**လှသော**ပန်း / ပန်း**လှ**" -> ဤနေရာတွင် 'လှ' သည် နာမ်ကို အထူးပြုသော **နာမဝိသေသန** ဖြစ်သည်။
- **အညွှန်းနာမ်စားနှင့် နာမဝိသေသန ရောထွေးခြင်း**: နာမ်မပါဘဲ သီးသန့်ရပ်တည်လျှင် နာမ်စားဖြစ်ပြီး၊ နာမ်နှင့် ပူးတွဲရပ်တည်မှသာ နာမဝိသေသန ဖြစ်သည်။

## Worked Example
- နာမဝိသေသန ခွဲခြမ်းစိတ်ဖြာမှု:
  - "**ဖြူသော** ခွေးကလေးသည် **အလွန်လျင်မြန်စွာ** ပြေးသည်။"
    - 'ဖြူသော' = ပင်ကိုနာမဝိသေသန (ခွေးကလေး နာမ်ကို အထူးပြုသည်)။
  - "သူသည် အတန်းထဲတွင် **ဉာဏ်အကောင်းဆုံး** ကျောင်းသား ဖြစ်သည်။"
    - 'ဉာဏ်အကောင်းဆုံး' = အသာလွန်ဆုံးအဆင့် နာမဝိသေသန။

## Key Takeaways
1. နာမဝိသေသနသည် နာမ် သို့မဟုတ် နာမ်စားကို အထူးပြုသည်။
2. ပင်ကို၊ အညွှန်း၊ သင်္ချာနှင့် အမေး နာမဝိသေသနများ ရှိသည်။
3. နှိုင်းယှဉ်အဆင့် ၃ ဆင့် (သာမန်၊ သာလွန်၊ အသာလွန်ဆုံး) ဖြင့် အနက်အဆင့်ကို ဖော်ပြသည်။
