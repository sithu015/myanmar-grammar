# Chapter 9: ပုဒ် ၄ မျိုး (Four Morphological Word Types)

## Core Idea
မြန်မာသဒ္ဒါတွင် ပုဒ်များကို အတွင်းဖွဲ့စည်းတည်ဆောက်ပုံ (Morphology) အရ ပုဒ်ရိုး၊ ပေါင်းစပ်ပုဒ်၊ ပစ္စည်းရောပုဒ်၊ ဝိဘတ်သွယ်ပုဒ် ဟူ၍ ၄ မျိုး တိကျစွာ ခွဲခြားထားသည်။

## Frameworks Introduced
- **ပုဒ် ၄ မျိုး တည်ဆောက်ပုံ မူဘောင် (4-Part Word Morphology Framework)**:
  1. **ပုဒ်ရိုး (Root/Simple Word)**: မူလအခြေခံ အနက်ရှိသော စကားလုံးတစ်လုံးတည်းဖြင့် ဖွဲ့စည်းထားသည့်ပုဒ် (ဥပမာ- လူ၊ ရေ၊ သွား၊ လာ၊ ကောင်း)။
  2. **ပေါင်းစပ်ပုဒ် (Compound Word)**: သီးခြားအနက်ရှိသော ပုဒ်ရိုးနှစ်ခု သို့မဟုတ် နှစ်ခုထက်ပို၍ ပေါင်းစပ်ဖွဲ့စည်းထားသည့်ပုဒ် (ဥပမာ- ရေ + အိုး = ရေအိုး၊ စာ + အုပ် = စာအုပ်၊ သွား + လာ = သွားလာ)။
  3. **ပစ္စည်းရောပုဒ် (Derived Word via Affixation)**: ပုဒ်ရိုးတစ်ခုတွင် နာမ်ပစ္စည်း သို့မဟုတ် ကြိယာပစ္စည်းတစ်ခုခုကို ရှေ့ဆက်/နောက်ဆက် ပေါင်းစပ်၍ ဝါစင်္ဂအသစ်အဖြစ် ပြောင်းလဲထားသည့်ပုဒ် (ဥပမာ- အ + သောက် = အသောက်၊ စား + ခြင်း = စားခြင်း၊ စာ + သမား = စာသမား)။
  4. **ဝိဘတ်သွယ်ပုဒ် (Inflected Word via Clitics)**: နာမ် သို့မဟုတ် ကြိယာပုဒ်တွင် ဝိဘတ်တစ်ခုခု သွယ်ဆက်ထားသည့်ပုဒ် (ဥပမာ- လူ + ကို = လူကို၊ သွား + သည် = သွားသည်)။

## Key Concepts
- **ပုဒ်ရိုး**: နောက်ထပ် ခွဲစိတ်၍မရသော အခြေခံသဒ္ဒါအမြစ် (Morpheme/Root)။
- **ပေါင်းစပ်ပုဒ်**: မူလပုဒ်များ ပေါင်းစပ်ပြီး အနက်အသစ် သို့မဟုတ် အနက်ကျယ်ဝန်းမှု ဖြစ်ထွန်းလာသောပုဒ်။
- **ပစ္စည်းရောပုဒ်**: 'အ-' ရှေ့ဆက် သို့မဟုတ် '-ခြင်း၊ -မှူး၊ -သမား' စသော ပစ္စည်းများဖြင့် ဖွဲ့စည်းသောပုဒ်။
- **ဝိဘတ်သွယ်ပုဒ်**: ဝါကျတွင်း အခန်းကဏ္ဍထင်ရှားစေရန် ဝိဘတ်တပ်ဆင်ထားသောပုဒ်။

## Mental Models
- **သစ်ပင်ကြီးထွားမှု မော်ဒယ်**:
  - ပုဒ်ရိုး = အမြစ် (Root)
  - ပေါင်းစပ်ပုဒ် = ကိုင်းကူးကိုင်းဆက် (Grafting)
  - ပစ္စည်းရောပုဒ် = ရွက်နုနှင့် အပွင့်ဝေဆာမှု (Derivation)
  - ဝိဘတ်သွယ်ပုဒ် = ဥယျာဉ်ခြံစည်းရိုးအတွင်း နေရာချထားမှု (Syntax Placement)

## Anti-patterns
- **ပေါင်းစပ်ပုဒ်နှင့် ပစ္စည်းရောပုဒ်ကို ရောထွေးခြင်း**: ပေါင်းစပ်ပုဒ်သည် အနက်ရှိသော စကားလုံးနှစ်ခုပေါင်းခြင်းဖြစ်ပြီး၊ ပစ္စည်းရောပုဒ်သည် သီးခြားအနက်မရှိသော ပစ္စည်း (Affix) ကို ကပ်တွဲခြင်းဖြစ်သည်ကို သတိမပြုမိခြင်း။

## Worked Example
- ပုဒ် ၄ မျိုး ခွဲခြမ်းစိတ်ဖြာပြခြင်း:
  1. "စာ" -> ပုဒ်ရိုး။
  2. "စာကြည့်တိုက်" -> ပေါင်းစပ်ပုဒ် (စာ + ကြည့် + တိုက်)။
  3. "စာရေးခြင်း" -> ပစ္စည်းရောပုဒ် (စာရေး + ခြင်း)။
  4. "စာကြည့်တိုက်သို့" -> ဝိဘတ်သွယ်ပုဒ် (စာကြည့်တိုက် + သို့)။

## Key Takeaways
1. ပုဒ် ၄ မျိုးသည် မြန်မာစကားလုံး ကြွယ်ဝမှု၏ ပင်မယန္တရားဖြစ်သည်။
2. ပုဒ်ရိုးသည် အခြေခံဖြစ်ပြီး ပေါင်းစပ်ပုဒ်နှင့် ပစ္စည်းရောပုဒ်တို့သည် စကားလုံးသစ် ထုတ်လုပ်မှုဖြစ်သည်။
3. ဝိဘတ်သွယ်ပုဒ်သည် ဝါကျဖွဲ့စည်းမှုအတွက် မရှိမဖြစ် လိုအပ်သည်။
