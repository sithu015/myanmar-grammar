# Chapter 14: ဝါစင်္ဂ - ကြိယာဝိသေသန (Word Classes: Adverbs)

## Core Idea
ကြိယာဝိသေသနဆိုသည်မှာ ကြိယာ သို့မဟုတ် နာမဝိသေသနတို့၏ ပြုမူပုံ၊ ဖြစ်ပျက်ပုံ၊ အချိန်ကာလ၊ နေရာဒေသနှင့် အတိုင်းအဆ အခြေအနေတို့ကို ပိုမိုတိကျရှင်းလင်းအောင် အထူးပြုဖော်ပြသော စကားလုံး ဖြစ်သည်။

## Frameworks Introduced
- **ကြိယာဝိသေသန ဖွဲ့စည်းပုံ မူဘောင် (Adverb Formation Framework)**:
  1. **ပစ္စည်းနောက်ဆက် ကြိယာဝိသေသန**: ကြိယာ သို့မဟုတ် နာမဝိသေသနနောက်၌ 'စွာ' ပစ္စည်းဆက်ခြင်း (ဥပမာ- ကောင်း'စွာ'၊ မြန်'စွာ'၊ ဖြည်းညင်း'စွာ')။
  2. **ပစ္စည်းရှေ့ဆက် ကြိယာဝိသေသန**: ရှေ့၌ 'အ-' ပစ္စည်းဆက်၍ အသံထပ်ခြင်း (ဥပမာ- 'အ'မြန်၊ 'အ'လွန်)။
  3. **နှစ်ကြိမ်ထပ် ကြိယာဝိသေသန**: စကားလုံးကို နှစ်ခါထပ်၍ ကြိယာဝိသေသနပြုခြင်း (ဥပမာ- မြန်မြန်၊ ဖြည်းဖြည်း၊ ကောင်းကောင်း)။
  4. **ကာရန်လိုက် ကြိယာဝိသေသန (၄ လုံးစပ်)**: ကာရန်ညီစကားလုံး ၄ လုံးဖြင့် ဖွဲ့စည်းခြင်း (ဥပမာ- ကမန်းကတန်း၊ လောလောလတ်လတ်၊ တအိအိ)။
- **အနက်သဘောအရ ခွဲခြားမှု မူဘောင်**:
  - အမူအရာပြ (Manner) - ကောင်းစွာ၊ သွက်လက်စွာ။
  - အချိန်ပြ (Time) - ယခု၊ မကြာမီ၊ ချက်ချင်း။
  - နေရာပြ (Place) - အနီး၊ အဝေး၊ ဤအရပ်၌။
  - အတိုင်းအတာပြ (Degree) - အလွန်၊ အလွန်အမင်း၊ အထူးသဖြင့်။

## Key Concepts
- **ကြိယာဝိသေသန**: ကြိယာကို အထူးပြုသော ဝါစင်္ဂ။
- **နှစ်ကြိမ်ထပ်စကားလုံး**: ကြိယာကို အနက်လေးနက်စေရန် ထပ်ဆိုသောအသုံး။
- **စွာ-ပစ္စည်း**: နာမဝိသေသနကို ကြိယာဝိသေသနအဖြစ် အသွင်ပြောင်းပေးသော အဓိကပစ္စည်း။

## Mental Models
- **အရှိန်နှင့် လမ်းကြောင်း ထိန်းချုပ်စနစ် မော်ဒယ်**: ကြိယာသည် ပြေးလွှားလှုပ်ရှားနေသော ကားတစ်စီးဖြစ်ပါက၊ ကြိယာဝိသေသနသည် ထိုကား "ဘယ်လိုပြေးသလဲ (မြန်မြန်)"၊ "ဘယ်ကိုပြေးသလဲ (ရှေ့သို့)"၊ "ဘယ်အချိန်က ပြေးသလဲ (မနေ့က)" ကို ညွှန်ပြပေးသည့် ဒိုင်ခွက်နှင့် မောင်းနှင်မှု ပုံစံဖြစ်သည်။

## Anti-patterns
- **နာမဝိသေသနနှင့် ကြိယာဝိသေသန ရောထွေးခြင်း**:
  - "သူသည် ကောင်းသောလူ ဖြစ်သည်" -> 'ကောင်းသော' သည် လူ(နာမ်)ကို အထူးပြုသဖြင့် **နာမဝိသေသန** ဖြစ်သည်။
  - "သူသည် ကောင်းစွာ လုပ်သည်" -> 'ကောင်းစွာ' သည် လုပ်(ကြိယာ)ကို အထူးပြုသဖြင့် **ကြိယာဝိသေသန** ဖြစ်သည်။

## Worked Example
- ကြိယာဝိသေသန ခွဲခြမ်းစိတ်ဖြာမှု:
  - "မိုးသည် **သည်းထန်စွာ** ရွာသွန်းနေသည်။" -> 'သည်းထန်စွာ' = 'စွာ' ပစ္စည်းနောက်ဆက် ကြိယာဝိသေသန (ရွာသွန်း ကြိယာကို အထူးပြုသည်)။
  - "သူတို့သည် **ကမန်းကတန်း** ပြေးလာကြသည်။" -> 'ကမန်းကတန်း' = ၄ လုံးစပ် ကာရန်လိုက် ကြိယာဝိသေသန။
  - "ထမင်းကို **မြန်မြန်** စားပါ။" -> 'မြန်မြန်' = နှစ်ကြိမ်ထပ် ကြိယာဝိသေသန။

## Key Takeaways
1. ကြိယာဝိသေသနသည် ကြိယာ၏ အမူအရာ၊ အချိန်၊ နေရာ၊ ပမာဏကို အထူးပြုသည်။
2. 'စွာ' ပစ္စည်းဆက်ခြင်း၊ နှစ်ကြိမ်ထပ်ခြင်း၊ 'အ-' ရှေ့ဆက်ခြင်းတို့ဖြင့် ဖွဲ့စည်းသည်။
3. နာမ်ကို အထူးပြုလျှင် နာမဝိသေသန၊ ကြိယာကို အထူးပြုလျှင် ကြိယာဝိသေသန ဖြစ်သည်။
