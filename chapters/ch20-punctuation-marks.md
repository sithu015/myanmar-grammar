# Chapter 20: ပုဒ်ဖြတ်ပုဒ်ရပ်သင်္ကေတများ (Punctuation Marks)

## Core Idea
ပုဒ်ဖြတ်ပုဒ်ရပ်သင်္ကေတများသည် မြန်မာစာ ရေးသားဖတ်ရှုရာတွင် အသံနားရမည့်နေရာ၊ စကားအဓိပ္ပာယ် ပိုင်းခြားရမည့်နေရာနှင့် ဝါကျပြီးဆုံးမှုကို မျက်စိဖြင့် ထင်ရှားစွာ မြင်တွေ့စေသော အမှတ်အသားများ ဖြစ်ကြသည်။

## Frameworks Introduced
- **မြန်မာ ပုဒ်ဖြတ်ပုဒ်ရပ် စည်းမျဉ်း မူဘောင် (Punctuation Rules Framework)**:
  1. **ပုဒ်ကလေး သို့မဟုတ် ပုဒ်ဖြတ် (၊)**:
     - စကားအနက် မပြည့်စုံသေးဘဲ စကားအဆက်အစပ်ကို ခေတ္တနား၍ ဖတ်ရန် ပြသောသင်္ကေတ (Comma)။
     - အမည်များ၊ စာရင်းများကို ဆက်တိုက်ဖော်ပြရာတွင် သုံးသည် (ဥပမာ- "မောင်မောင်၊ အောင်အောင်၊ လှလှတို့ လာကြသည်")။
  2. **ပုဒ်မ သို့မဟုတ် ပုဒ်ရပ် (။)**:
     - ဝါကျတစ်ခု အဓိပ္ပာယ် ပြည့်စုံစွာ ပြီးဆုံးသွားကြောင်း ပြသောသင်္ကေတ (Full Stop/Period)။
  3. **မျဉ်းစောင်း သို့မဟုတ် ပုဒ်မကွဲ (/)**:
     - အကြောင်းအရာတစ်ခုနှင့် တစ်ခု သို့မဟုတ် စာပိုဒ်တစ်ခုနှင့် တစ်ခုကို ခွဲခြားပြသော သင်္ကေတ။
  4. **မျက်တောင်ဖွင့် မျက်တောင်ပိတ် (“ ”)**:
     - စကားပြော၊ တိုက်ရိုက်ကောက်နုတ်ချက်၊ အထူးပြုဝေါဟာရများကို ထည့်သွင်းပြသသည့် သင်္ကေတ (Quotation Marks)။
  5. **လက်သည်းကွင်း သို့မဟုတ် ကွင်းစကွင်းပိတ် ( )**:
     - ထပ်ဆင့်ရှင်းလင်းချက်၊ စကားချပ် သို့မဟုတ် အခြားအမည်ကို ဖော်ပြသည့် သင်္ကေတ (Parentheses)။
  6. **စာမြှုပ်သင်္ကေတ သို့မဟုတ် အစက်ကလေးများ ( ... )**:
     - စာသားအချို့ကို ချန်လှပ်မြှုပ်နှံထားကြောင်း ပြသော သင်္ကေတ (Ellipsis)။

## Key Concepts
- **ပုဒ်ကလေး (၊)**: အသံခေတ္တနားရန်နှင့် စာသားခွဲခြားရန် သုံးသော သင်္ကေတ။
- **ပုဒ်မ (။)**: ဝါကျ အပြီးသတ်ကြောင်း ပြသော ပင်မသင်္ကေတ။
- **စာပုဒ် (Clause/Paragraph)**: ပုဒ်ဖြတ်ပုဒ်ရပ်တို့ဖြင့် စနစ်တကျ အကန့်ခွဲထားသော စာသားအစု။

## Mental Models
- **ယာဉ်စည်းကမ်း မီးပွိုင့် မော်ဒယ်**:
  - ပုဒ်ကလေး (၊) = အဝါရောင်မီး (အရှိန်လျှော့၍ အနည်းငယ်နားပါ)။
  - ပုဒ်မ (။) = အနီရောင်မီး (ဝါကျပြီးဆုံးသဖြင့် လုံးဝရပ်တန့်ပါ)။

## Anti-patterns
- **ပုဒ်ကလေးနှင့် ပုဒ်မ မပါဘဲ စာကြောင်းရှည်ကြီး ဆက်တိုက်ရေးခြင်း**: စာဖတ်သူအား အသက်ရှူရပ်စေပြီး အဓိပ္ပာယ် ကောက်ယူလွဲမှားစေခြင်း။
- **ဝါကျမပြီးဆုံးသေးဘဲ ပုဒ်မ (။) အဆောတလျင် ချမိခြင်း**: ဝါကျအနက် မပြည့်စုံဘဲ ပြတ်တောက်သွားစေခြင်း။

## Worked Example
- ပုဒ်ဖြတ်ပုဒ်ရပ် သုံးစွဲပုံ နမူနာ:
  - "မြန်မာနိုင်ငံတွင် ရန်ကုန်၊ မန္တလေး၊ နေပြည်တော် စသော မြို့ကြီးများ ရှိသည်။"
    - ရန်ကုန် နှင့် မန္တလေး ကြားတွင် ပုဒ်ကလေး (၊) ဖြင့် အမည်များကို ပိုင်းခြားသည်။
    - စာကြောင်းအဆုံးတွင် ပုဒ်မ (။) ဖြင့် ဝါကျအဆုံးသတ်သည်။
  - "ဆရာက 'စာကြိုးစားကြပါ' ဟု မှာကြားခဲ့သည်။"
    - ဆရာ၏ တိုက်ရိုက်စကားကို မျက်တောင် (' ') ဖြင့် ဖော်ပြသည်။

## Key Takeaways
1. ပုဒ်ကလေး (၊) သည် စကားဆက်စပ်မှုကို ခေတ္တနားစေသည်။
2. ပုဒ်မ (။) သည် ဝါကျပြီးမြောက်ကြောင်း ပြသည်။
3. ပုဒ်ဖြတ်ပုဒ်ရပ် မှန်ကန်စွာ သုံးခြင်းသည် စာဖတ်သူကို အဓိပ္ပာယ် တိကျစွာ နားလည်စေသည်။
