# Chapter 19: ဝါကျကဏ္ဍ၊ ခွဲခြမ်းစိတ်ဖြာခြင်းနှင့် စကားအထားအသို (Clauses, Parsing, and Word Order)

## Core Idea
ဝါကျရောတစ်ခုအတွင်း၌ အမှီဝါကျကဏ္ဍ ၃ မျိုး (နာမ်ဝါကျကဏ္ဍ၊ နာမဝိသေသနဝါကျကဏ္ဍ၊ ကြိယာဝိသေသနဝါကျကဏ္ဍ) ပါဝင်ဖွဲ့စည်းနိုင်ပြီး၊ ဝါကျခွဲခြမ်းစိတ်ဖြာခြင်း (Parsing) နှင့် သဒ္ဒါနည်းကျ စကားအထားအသို စည်းမျဉ်းများဖြင့် စနစ်တကျ လေ့လာဆန်းစစ်နိုင်သည်။

## Frameworks Introduced
- **အမှီဝါကျကဏ္ဍ ၃ မျိုး မူဘောင် (3 Subordinate Clause Types Framework)**:
  1. **နာမ်ဝါကျကဏ္ဍ (Noun Clause)**: ဝါကျကြီးအတွင်း ကတ္တား သို့မဟုတ် ကံနေရာ၌ နာမ်ပုဒ်သဖွယ် တာဝန်ယူသော အမှီဝါကျ (ဥပမာ- "သူ လာမည်ကို / သူ ပြောသည်မှာ")။
  2. **နာမဝိသေသနဝါကျကဏ္ဍ (Adjective Clause)**: ပင်မဝါကျရှိ နာမ်တစ်ခုခုကို အထူးပြုသော အမှီဝါကျ (ဥပမာ- "မနေ့က ရောက်လာ'သော' ဧည့်သည်")။
  3. **ကြိယာဝိသေသနဝါကျကဏ္ဍ (Adverb Clause)**: ပင်မကြိယာ၏ အချိန်၊ အကြောင်းရင်း၊ အခြေအနေကို ပြသော အမှီဝါကျ (ဥပမာ- "မိုးရွာ'သဖြင့်' / အိပ်ရာထ'သောအခါ'")။
- **ဝါကျခွဲခြမ်းစိတ်ဖြာခြင်း မူဘောင် (Sentence Parsing Framework)**:
  - အဆင့် ၁: ပင်မကြိယာနှင့် ကတ္တားကို ရှာဖွေခြင်း။
  - အဆင့် ၂: ကံပုဒ်နှင့် အထူးပြုပုဒ်များကို သီးခြားခွဲထုတ်ခြင်း။
  - အဆင့် ၃: အမှီဝါကျကဏ္ဍများ၏ အနက်ဆက်သွယ်မှုကို သတ်မှတ်ခြင်း။

## Key Concepts
- **ဝါကျကဏ္ဍ (Clause)**: ဝါကျကြီးတစ်ခု၏ အတွင်း၌ ပါဝင်သော ဝါကျငယ်အစိတ်အပိုင်း။
- **အမှီဝါကျ (Subordinate Clause)**: သီးခြားရပ်တည်၍ အဓိပ္ပာယ်မပြည့်စုံဘဲ ပင်မဝါကျကို အမှီပြုရသော အစိတ်အပိုင်း။
- **အမှီခံဝါကျ/ပင်မဝါကျ (Main Clause)**: သီးခြားရပ်တည်နိုင်သော အဓိကဝါကျ။
- **စကားအထားအသို (Word Order)**: ကတ္တား၊ ကံ၊ ကြိယာနှင့် အထူးပြုပုဒ်များ၏ သဒ္ဒါနည်းကျ နေရာချထားပုံ။

## Mental Models
- **ကြိုးဆွဲရုပ်နှင့် ကြိုးများ မော်ဒယ်**: ပင်မဝါကျသည် ကြိုးဆွဲရုပ်ဖြစ်ပြီး အမှီဝါကျကဏ္ဍများသည် ထိုရုပ်ကို လှုပ်ရှားစေရန် ချိတ်ဆက်ထားသော ကြိုးမျှင်များ ဖြစ်ကြသည်။ ကြိုးတစ်ချောင်းချင်းစီ၏ အခန်းကဏ္ဍ (နာမ်၊ နာမဝိသေသန၊ ကြိယာဝိသေသန) ကို ခွဲစိတ်သိရှိခြင်းသည် ဝါကျခွဲခြမ်းစိတ်ဖြာခြင်း ဖြစ်သည်။

## Anti-patterns
- **အမှီဝါကျကို ဝါကျအပြည့်အစုံအဖြစ် ပုဒ်မချရပ်တန့်ခြင်း**: "သူ လာသောအခါ။" ဟူ၍ အမှီဝါကျကဏ္ဍသက်သက်ကို ဝါကျအဖြစ် ရေးသားမိခြင်း (ပင်မကြိယာ မပါဝင်သဖြင့် အနက်မပြည့်စုံပါ)။
- **နာမဝိသေသနဝါကျကဏ္ဍကို နာမ်ဝါကျကဏ္ဍနှင့် မှားယွင်းသတ်မှတ်ခြင်း**: နာမ်ကို အထူးပြုနေသော 'သော' ပါ ဝါကျကဏ္ဍကို သတိမပြုမိခြင်း။

## Worked Example
- ဝါကျခွဲခြမ်းစိတ်ဖြာပြခြင်း:
  - ဝါကျ: **"စာကြိုးစားသော မောင်မောင်သည် စာမေးပွဲ ဖြေဆိုသောအခါ ပထမဆုကို ရရှိခဲ့သည်။"**
    - ပင်မဝါကျ (အမှီခံဝါကျ): မောင်မောင်သည် ပထမဆုကို ရရှိခဲ့သည်။
    - နာမဝိသေသနဝါကျကဏ္ဍ: "စာကြိုးစားသော" (မောင်မောင် နာမ်ကို အထူးပြုသည်)။
    - ကြိယာဝိသေသနဝါကျကဏ္ဍ: "စာမေးပွဲ ဖြေဆိုသောအခါ" (အချိန်ပြ ကြိယာဝိသေသန အမှီဝါကျ)။
    - ကတ္တား: မောင်မောင်
    - ကံ: ပထမဆု
    - ကြိယာ: ရရှိခဲ့သည်

## Key Takeaways
1. ဝါကျရောတွင် အမှီဝါကျကဏ္ဍ ၃ မျိုး (နာမ်၊ နာမဝိသေသန၊ ကြိယာဝိသေသန) ပါဝင်သည်။
2. ဝါကျခွဲခြမ်းစိတ်ဖြာခြင်းသည် ရှုပ်ထွေးသော စာကြောင်းများကို ရှင်းလင်းစွာ နားလည်စေသည်။
3. အမှီဝါကျသည် သီးခြားရပ်တည်၍ မရဘဲ ပင်မဝါကျနှင့် တွဲဖက်ရသည်။
