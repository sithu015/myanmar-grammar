# Chapter 10: ဝါစင်္ဂ - နာမ် (Word Classes: Nouns)

## Core Idea
နာမ်ဆိုသည်မှာ လူ၊ တိရစ္ဆာန်၊ အရာဝတ္ထု၊ နေရာဒေသ၊ အချိန်၊ အခြင်းအရာနှင့် သဘောတရားတို့ကို အမည်ပေး၍ ရည်ညွှန်းခေါ်ဆိုသော စကားလုံးဖြစ်ပြီး၊ သဒ္ဒါအရ အမျိုးအစား ၅ မျိုးနှင့် လိင်၊ ကိန်း သဘောတရားများ ပါဝင်သည်။

## Frameworks Introduced
- **နာမ် ၅ မျိုး ခွဲခြားမှု မူဘောင် (5 Noun Classes Framework)**:
  1. **သမ္မာနာမ် (Proper Noun)**: သီးခြားပုဂ္ဂိုလ်၊ နေရာ၊ အရာဝတ္ထုတစ်ခုတည်းကိုသာ သီးသန့်ရည်ညွှန်းသောအမည် (ဥပမာ- ရန်ကုန်၊ မောင်မောင်၊ ဧရာဝတီမြစ်)။
  2. **သာမညနာမ် (Common Noun)**: အလားတူအရာ အားလုံးနှင့် သက်ဆိုင်သောအထွေထွေအမည် (ဥပမာ- လူ၊ မြို့၊ မြစ်၊ ကျောင်း၊ ခွေး)။
  3. **စုပေါင်းနာမ် (Collective Noun)**: အများအပေါင်းကို တစ်ခုတည်းအဖြစ် စုစည်းခေါ်ဆိုသောအမည် (ဥပမာ- တပ်မတော်၊ အသင်း၊ ပရိသတ်၊ သစ်တော)။
  4. **ဒြပ်ရှိနာမ် (Concrete Noun)**: ကိုင်တွယ်ထိတွေ့ မြင်တွေ့နိုင်သောအရာများ (ဥပမာ- စားပွဲ၊ ရွှေ၊ ရေ၊ ကျောက်တုံး)။
  5. **ဒြပ်မဲ့နာမ် (Abstract Noun)**: စိတ်ဖြင့်သာ သိနိုင်သော အခြင်းအရာ၊ စိတ်ခံစားမှု၊ ဂုဏ်ရည်များ (ဥပမာ- ပညာ၊ မေတ္တာ၊ လွတ်လပ်ရေး၊ စေတနာ)။
- **လိင်နှင့် ကိန်း မူဘောင် (Gender and Number Framework)**:
  - **လိင် ၄ မျိုး**: ပုလ္လိင် (ဖိုမပြ)၊ ဣတ္ထိလိင် (မပြ)၊ နပုလ္လိင် (ဖိုမမပြ/အရာဝတ္ထု)၊ ဝိသေသလိင် (ဖိုမနှစ်မျိုးလုံးသုံးနိုင်သောနာမ်)။
  - **ကိန်း ၂ မျိုး**: ဧကဝုစ် (တစ်ပါး/တစ်ခုပြ) နှင့် ဗဟုဝုစ် (အများပြ - တို့၊ များ၊ အပေါင်း)။

## Key Concepts
- **နာမ် (Noun)**: အမည်ဟူသမျှကို ရည်ညွှန်းသော ဝါစင်္ဂ။
- **နာမ်ဖြစ်ပစ္စည်း**: ကြိယာ သို့မဟုတ် နာမဝိသေသနကို နာမ်ဖြစ်အောင် ပြောင်းပေးသော ပစ္စည်း (ဥပမာ- 'အ-' ရှေ့ဆက် -> အလုပ်၊ အလှ၊ '-ခြင်း' -> သွားခြင်း)။
- **ကိန်းပြပစ္စည်း**: နာမ်ကို အများကိန်းဖြစ်စေသော စကားလုံးများ (ဥပမာ- ကျောင်းသား'များ'၊ သူငယ်ချင်း'တို့')။

## Mental Models
- **အမည်တံဆိပ် မော်ဒယ် (The Name Tag Model)**: လောကရှိ မြင်မြင်သမျှ၊ တွေးတွေးသမျှ အရာအားလုံးတွင် ကပ်ထားသော အမည်တံဆိပ်တိုင်းသည် "နာမ်" ဖြစ်သည်။

## Anti-patterns
- **ဒြပ်မဲ့နာမ်ကို နာမဝိသေသနဟု ထင်မှတ်ခြင်း**: "လှပသည်" (ကြိယာ/နာမဝိသေသန) နှင့် "အလှ" သို့မဟုတ် "လှပခြင်း" (ဒြပ်မဲ့နာမ်) ကို မခွဲခြားနိုင်ခြင်း။
- **အများကိန်းပစ္စည်းများကို အဆင်အခြင်မဲ့ ထပ်ဆင့်ခြင်း**: "ကျောင်းသားများတို့" ဟု ကိန်းပြပစ္စည်းနှစ်ခု ထပ်ဆင့်သုံးစွဲခြင်း။

## Worked Example
- နာမ်အမျိုးအစား ခွဲခြားမှု စိစစ်ချက်:
  - "ဒေါ်ခင်ကြည်" -> သမ္မာနာမ် (သီးသန့်လူပုဂ္ဂိုလ်)၊ ဣတ္ထိလိင် (မ)၊ ဧကဝုစ် (တစ်ဦးတည်း)။
  - "ကျောင်းသားများ" -> သာမညနာမ် (အထွေထွေအမည်)၊ ဗဟုဝုစ် ('များ' ကြောင့် အများကိန်း)။
  - "သစ္စာတရား" -> ဒြပ်မဲ့နာမ် (စိတ်ဖြင့်သာသိနိုင်သော ဂုဏ်သဘော)။

## Key Takeaways
1. နာမ်သည် လူ၊ အရာဝတ္ထု၊ သဘောတရားတို့၏ အမည်ဖြစ်သည်။
2. အဓိကအားဖြင့် ၅ မျိုး (သမ္မာနာမ်၊ သာမညနာမ်၊ စုပေါင်းနာမ်၊ ဒြပ်ရှိနာမ်၊ ဒြပ်မဲ့နာမ်) ရှိသည်။
3. လိင် (၄ မျိုး) နှင့် ကိန်း (၂ မျိုး) ဖြင့် နာမ်၏ အင်္ဂါရပ်ကို ပြည့်စုံစေသည်။
