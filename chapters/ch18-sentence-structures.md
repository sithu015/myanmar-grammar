# Chapter 18: ဝါကျဖွဲ့စည်းပုံ - ဝါကျရိုးနှင့် ဝါကျရော (Sentence Structures: Simple and Compound)

## Core Idea
ဝါကျဆိုသည်မှာ ဆိုလိုရင်း အနက်အဓိပ္ပာယ် အပြည့်အစုံ ရောက်အောင် စနစ်တကျ ဖွဲ့စည်းထားသော စကားအစုအဝေးဖြစ်ပြီး၊ ပင်မကြိယာတစ်ခုတည်းပါဝင်သော ဝါကျရိုးနှင့် ဝါကျရိုးများစွာ ပေါင်းစပ်ထားသော ဝါကျရောဟူ၍ အခြေခံ ၂ မျိုး ခွဲခြားသည်။

## Frameworks Introduced
- **ဝါကျ ၂ မျိုး ဖွဲ့စည်းမှု မူဘောင် (Sentence Classification Framework)**:
  1. **ဝါကျရိုး (Simple Sentence)**:
     - ကတ္တားနှင့် ပင်မကြိယာတစ်ခုတည်းဖြင့် ဖွဲ့စည်းထားသော ဝါကျ။
     - ပုံစံ: [ကတ္တား] + [ကံ] + [ကြိယာ] (ဥပမာ- "မောင်မောင်သည် ကျောင်းသို့ သွားသည်။")
  2. **ဝါကျရော (Compound/Complex Sentence)**:
     - ဝါကျငယ်များ (ဝါကျကဏ္ဍများ) နှစ်ခု သို့မဟုတ် နှစ်ခုထက်ပို၍ သမ္ဗန္ဓများဖြင့် ဆက်စပ်ဖွဲ့စည်းထားသော ဝါကျကြီး။
     - အဓိကဝါကျ (Main Clause) နှင့် အမှီဝါကျ (Subordinate Clause) တို့ ပါဝင်သည်။
     - (ဥပမာ- "မိုးရွာသော်လည်း သူသည် အလုပ်သို့ သွားသည်။")
- **ဝါကျရိုး ဖွဲ့နည်း အမျိုးမျိုး**:
  - ကတ္တား + ကြိယာ (ငှက် ပျံသည်။)
  - ကတ္တား + ကံ + ကြိယာ (နွား မြက် စားသည်။)
  - ကတ္တား + နေရာ + ကြိယာ (သူ အိမ်တွင် ရှိသည်။)

## Key Concepts
- **ဝါကျ (Sentence)**: အဓိပ္ပာယ်ပြည့်စုံသော စကားအစုအဝေး။
- **ဝါကျရိုး (Simple Sentence)**: အနက်ပြည့်စုံသော ကြိယာတစ်ရပ်တည်း ပါဝင်သော ဝါကျ။
- **ဝါကျရော (Compound/Complex Sentence)**: ဝါကျရိုးများ သို့မဟုတ် ဝါကျကဏ္ဍများ ရောယှက်ပေါင်းစပ်ထားသော ဝါကျ။
- **စကားအထားအသို**: မြန်မာဝါကျ၏ ပင်ကိုစည်းမျဉ်းဖြစ်သော Subject-Object-Verb (SOV) အစဉ်။

## Mental Models
- **အပင်တစ်ပင်နှင့် သစ်တော မော်ဒယ်**:
  - ဝါကျရိုး = ပင်စည်တစ်ခုတည်းရှိသော သစ်ပင်ငယ်တစ်ပင်။
  - ဝါကျရော = သစ်ပင်များစွာ အချင်းချင်း နွယ်ပင်များ (သမ္ဗန္ဓများ) ဖြင့် ချိတ်ဆက်ယှက်နွယ်နေသော သစ်တောကြီး။

## Anti-patterns
- **ကြိယာမပါဘဲ ဝါကျဟု သတ်မှတ်ခြင်း**: မြန်မာစာတွင် ကြိယာ (သို့မဟုတ် ကြိယာဝိဘတ်) မပါဝင်ဘဲ ဝါကျအပြည့်အစုံ မဖြစ်နိုင်ချေ။
- **SOV အထားအသို ချိုးဖောက်ခြင်း**: အင်္ဂလိပ်စာ SVO စနစ်အတိုင်း "မောင်မောင် စားသည် ထမင်းကို" ဟု ရေးသားမိခြင်း။

## Worked Example
- ဝါကျဖွဲ့စည်းပုံ စိစစ်ချက်:
  1. "နေ ထွက်သည်။" -> ကတ္တား (နေ) + ကံမလိုကြိယာ (ထွက်သည်) = **ဝါကျရိုး**။
  2. "ဆရာသည် တပည့်အား စာပေ သင်ကြားပေးသည်။" -> ကတ္တား + ကံ + ကြိယာ = **ဝါကျရိုး**။
  3. "နေထွက်လာသောအခါ ငှက်ကလေးများသည် အစာရှာရန် ပျံသန်းကြသည်။" -> အမှီဝါကျ (နေထွက်လာသောအခါ) + ပင်မဝါကျ (ငှက်ကလေးများသည် ပျံသန်းကြသည်) = **ဝါကျရော**။

## Key Takeaways
1. ဝါကျတွင် ဝါကျရိုးနှင့် ဝါကျရောဟူ၍ အခြေခံ ၂ မျိုး ရှိသည်။
2. မြန်မာဝါကျ၏ အခြေခံကျောရိုးသည် ကတ္တား - ကံ - ကြိယာ (SOV) ဖြစ်သည်။
3. ဝါကျရောသည် ဝါကျရိုးများကို သမ္ဗန္ဓများဖြင့် ချိတ်ဆက်ဖွဲ့စည်းထားခြင်း ဖြစ်သည်။
