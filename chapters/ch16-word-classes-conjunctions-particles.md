# Chapter 16: ဝါစင်္ဂ - သမ္ဗန္ဓနှင့် ပစ္စည်း (Word Classes: Conjunctions and Particles)

## Core Idea
သမ္ဗန္ဓဆိုသည်မှာ စကားလုံး၊ ပုဒ်၊ ပုဒ်စုနှင့် ဝါကျတို့ကို အချင်းချင်း ဆက်သွယ်ပေးသော စကားလုံး (Conjunction) ဖြစ်ပြီး၊ ပစ္စည်းဆိုသည်မှာ နာမ် သို့မဟုတ် ကြိယာတို့နှင့် တွဲဖက်ကာ အနက်အဓိပ္ပာယ်ကို ထူးခြားလေးနက်စေသော စကားလုံး (Particle/Affix) ဖြစ်သည်။

## Frameworks Introduced
- **သမ္ဗန္ဓ အမျိုးအစားများ မူဘောင် (Conjunction Categories Framework)**:
  1. **ပုဒ်ဆက်သမ္ဗန္ဓ**: ပုဒ်အချင်းချင်း ဆက်စပ်ပေးသောအရာ (နှင့်၊ သို့မဟုတ်) - "မောင်မောင်'နှင့်' အောင်အောင်"။
  2. **ဝါကျဆက်သမ္ဗန္ဓ**: ဝါကျအချင်းချင်း သို့မဟုတ် ဝါကျကဏ္ဍများကို ဆက်စပ်ပေးသောအရာ:
     - အကြောင်းပြသမ္ဗန္ဓ: သောကြောင့်၊ သဖြင့်၊ ချင်းကြောင့်။
     - ဆန့်ကျင်ပြသမ္ဗန္ဓ: သော်လည်း၊ သော်ငြားလည်း၊ သို့သော်။
     - ရလဒ်ပြသမ္ဗန္ဓ: ထို့ကြောင့်၊ သို့ဖြစ်၍။
     - အချိန်ပြသမ္ဗန္ဓ: သောအခါ၊ စဉ်၊ လျှင်။
- **ပစ္စည်း အမျိုးအစားများ မူဘောင် (Particle Categories Framework)**:
  1. **နာမ်ပစ္စည်း**: နာမ်နှင့်တွဲ၍ အနက်ထူးခြားစေသောအရာ (ဥပမာ- စာ'သမား'၊ ကြီး'မှူး'၊ သွား'ခြင်း'၊ 'အ'ရွယ်)။
  2. **ကြိယာပစ္စည်း**: ကြိယာနှင့်တွဲ၍ အနက်အထောက်အပံ့ပြုသောအရာ (ဥပမာ- သွား'ချင်'သည်၊ စား'နိုင်'သည်၊ လာ'ဖူး'သည်၊ မဖတ်'ရဲ'ပါ)။

## Key Concepts
- **သမ္ဗန္ဓ (Conjunction)**: စကားအဆက်အစပ်ကို ပြသော ဝါစင်္ဂ။
- **ပစ္စည်း (Particle/Affix)**: မူလပုဒ်တို့၏ သဘောသဘာဝနှင့် အနက်ကို အသွင်ပြောင်းလဲ ထောက်ပံ့ပေးသော စကားလုံး။
- **ဝါကျဆက်**: စာကြောင်းရှည်များ တည်ဆောက်ရာတွင် အဓိကနှင့် အမှီဝါကျတို့ကို ပေါင်းကူးပေးသောအရာ။

## Mental Models
- **တံတားနှင့် အရောင်တင်ပစ္စည်း မော်ဒယ်**:
  - သမ္ဗန္ဓ = ချောက်ကမ်းပါးနှစ်ဖက် (ဝါကျနှစ်ခု) ကို ဆက်သွယ်ပေးသော တံတား။
  - ပစ္စည်း = မူလပစ္စည်းကို အနက်အသစ်ရရှိအောင် အမွှမ်းတင်ပေးသော ဓာတ်ကူပစ္စည်း။

## Anti-patterns
- **ဝါကျဆက်သမ္ဗန္ဓနှင့် နာမ်ဝိဘတ် ရောထွေးခြင်း**: "နှင့်" သည် ပုဒ်နှစ်ခုကြားတွင် ဆက်လျှင် သမ္ဗန္ဓဖြစ်ပြီး ("မောင်မောင်'နှင့်' လှလှ")၊ ကြိယာကို အသုံးခံပြုရန် တွဲလျှင် ဝိဘတ်ဖြစ်သည် ("ဓား'နှင့်' လှီးသည်")။
- **သမ္ဗန္ဓအထားအသို မှားယွင်းခြင်း**: အကြောင်းနှင့် အကျိုး ဆက်စပ်မှုတွင် ဆန့်ကျင်ဘက် သမ္ဗန္ဓသုံးမိခြင်း (ဥပမာ- မိုးရွာသောကြောင့် သွားသည် vs မိုးရွာသော်လည်း သွားသည်)။

## Worked Example
- သမ္ဗန္ဓနှင့် ပစ္စည်း ခွဲခြမ်းစိတ်ဖြာမှု:
  - "သူသည် စာကြိုးစား**သော်လည်း** စာမေးပွဲ ကျရှုံးခဲ့သည်။" -> 'သော်လည်း' = ဆန့်ကျင်ပြ ဝါကျဆက်သမ္ဗန္ဓ။
  - "မိုးရွာ**သောကြောင့်** ကျောင်းပိတ်သည်။" -> 'သောကြောင့်' = အကြောင်းပြ ဝါကျဆက်သမ္ဗန္ဓ။
  - "သူသည် စာအုပ်ကို ဖတ်**ချင်**သည်။" -> 'ချင်' = ကြိယာပစ္စည်း (ဆန္ဒရှိခြင်းကို ပြသည်)။

## Key Takeaways
1. သမ္ဗန္ဓသည် ဝါကျနှင့် ပုဒ်များကို အချင်းချင်း ပေါင်းကူးဆက်စပ်ပေးသည်။
2. ပစ္စည်းသည် နာမ်နှင့် ကြိယာတို့၏ အနက်ကို ပြောင်းလဲချဲ့ထွင်ပေးသည်။
3. ဝါကျရှည် (ဝါကျရော) တည်ဆောက်ရာတွင် သမ္ဗန္ဓသည် မရှိမဖြစ် အရေးပါသည်။
