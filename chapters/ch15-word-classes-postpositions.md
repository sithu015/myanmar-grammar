# Chapter 15: ဝါစင်္ဂ - ဝိဘတ် (Word Classes: Postpositions/Case Markers)

## Core Idea
ဝိဘတ်ဆိုသည်မှာ နာမ် သို့မဟုတ် ကြိယာတို့၏ နောက်တွင် သွယ်ဆက်ကပ်ပါပြီး ဝါကျအတွင်း ထိုပုဒ်တို့၏ ကတ္တား၊ ကံ၊ နေရာ၊ အချိန် စသော သဒ္ဒါဆိုင်ရာ အခန်းကဏ္ဍ (Case) နှင့် ကာလတို့ကို တိကျစွာ ဖော်ပြပေးသော ဝါစင်္ဂ ဖြစ်သည်။

## Frameworks Introduced
- **နာမ်ဝိဘတ် ၇ မျိုး မူဘောင် (Noun Case Markers Framework)**:
  1. **ကတ္တားဝိဘတ် (Nominative)**: ပြုလုပ်သူကို ပြသည် (သည်၊ က၊ မှာ) - "မောင်မောင်'သည်' စာဖတ်သည်"။
  2. **ကံဝိဘတ် (Accusative)**: အပြုခံရသောအရာကို ပြသည် (ကို) - "ထမင်း'ကို' စားသည်"။
  3. **ထွက်ခွာရာပြဝိဘတ် (Ablative)**: စတင်ထွက်ခွာရာ နေရာ/အချိန်ကို ပြသည် (မှ၊ က) - "ရန်ကုန်'မှ' လာသည်"။
  4. **ရှေးရှုရာပြဝိဘတ် (Dative/Directive)**: ရောက်ရှိရာ ဦးတည်ချက်ကို ပြသည် (သို့၊ အား) - "ကျောင်း'သို့' သွားသည်"၊ "သူ့'အား' ပေးသည်"။
  5. **နေရာပြဝိဘတ် (Locative)**: တည်ရှိရာ အရပ်နှင့် အချိန်ကို ပြသည် (တွင်၊ ၌၊ မှာ) - "အိမ်'တွင်' ရှိသည်"။
  6. **အသုံးခံပြဝိဘတ် (Instrumental)**: အသုံးပြုသောအရာ/အကြောင်းရင်းကို ပြသည် (ဖြင့်၊ နှင့်) - "ဓား'ဖြင့်' လှီးသည်"။
  7. **ပိုင်ဆိုင်ရာပြဝိဘတ် (Genitive)**: ပိုင်ဆိုင်မှုကို ပြသည် (၏) - "ငါ'၏' စာအုပ်"။
- **ကြိယာဝိဘတ် မူဘောင် (Verb Particles/Endings Framework)**:
  - ကြိယာ၏ အဆုံးတွင်ရပ်တည်၍ ဝါကျပြီးမြောက်ကြောင်းနှင့် ကာလကို ပြသည် (သည်၊ ၏၊ မည်၊ အံ့၊ ခဲ့၊ ပြီ၊ လော့)။

## Key Concepts
- **ဝိဘတ် (Case Marker/Postposition)**: သဒ္ဒါဆက်သွယ်မှုကို ပြသော စကားလုံး။
- **ကတ္တား (Subject)**: ဝါကျအတွင်း ပြုလုပ်သူ။
- **ကံ (Object)**: ပြုလုပ်ခြင်း ခံရသူ။
- **ပိုင်ဆိုင်ရာ (Possessive)**: အရာဝတ္ထုတစ်ခု၏ ပိုင်ရှင်ဖြစ်ကြောင်း ပြခြင်း။

## Mental Models
- **သဒ္ဒါလမ်းညွှန်ဆိုင်းဘုတ် မော်ဒယ်**: ဝိဘတ်များသည် ဝါကျတွင်းရှိ စကားလုံးတစ်လုံးချင်းစီ၏ လည်ပင်းတွင် ဆွဲထားသော ဆိုင်းဘုတ်များ ဖြစ်ကြသည်။ "သည်" ဟုပါလျှင် ပြုလုပ်သူဖြစ်ကြောင်း၊ "ကို" ဟုပါလျှင် အပြုခံဖြစ်ကြောင်း ရှင်းလင်းစွာ ခွဲခြားသိမြင်စေသည်။

## Anti-patterns
- **ဝိဘတ်အသုံး မှားယွင်းခြင်း**:
  - ထွက်ခွာရာနှင့် နေရာပြ ရောထွေးခြင်း: "ရန်ကုန်'မှာ' လာသည်" ဟု မသုံးရ၊ "ရန်ကုန်'မှ' လာသည်" ဟု သုံးရမည်။
  - အသုံးခံနှင့် ကံ ရောထွေးခြင်း: "ဘောပင်'ကို' ရေးသည်" မဟုတ်၊ "ဘောပင်'ဖြင့်' ရေးသည်" ဟု သုံးရမည်။

## Worked Example
- ဝိဘတ်များ ခွဲခြမ်းစိတ်ဖြာမှု:
  - "ဆရာ**သည်** ကျောင်းသားများ**အား** စာကြည့်တိုက်**၌** စာအုပ်များ**ကို** မေတ္တာ**ဖြင့်** သင်ပြ**သည်။**"
    - 'သည်' = ကတ္တားဝိဘတ် (ဆရာ)။
    - 'အား' = ရှေးရှုရာ/ခံယူသူဝိဘတ် (ကျောင်းသားများ)။
    - '၌' = နေရာပြဝိဘတ် (စာကြည့်တိုက်)။
    - 'ကို' = ကံဝိဘတ် (စာအုပ်များ)။
    - 'ဖြင့်' = အသုံးခံ/အမူအရာပြဝိဘတ် (မေတ္တာ)။
    - 'သည်' = ကြိယာဝိဘတ် (သင်ပြ)။

## Key Takeaways
1. နာမ်ဝိဘတ် ၇ မျိုးသည် ဝါကျတွင်း ပုဒ်တစ်ခုစီ၏ တာဝန်ကို ခွဲခြားသတ်မှတ်သည်။
2. ကြိယာဝိဘတ်သည် ဝါကျကို အဆုံးသတ်ပြီး ကာလကို ဖော်ပြသည်။
3. ဝိဘတ်တိကျစွာ သုံးစွဲခြင်းသည် သဒ္ဒါကျစ်လျစ်မှန်ကန်မှု၏ အဓိကသော့ချက် ဖြစ်သည်။
