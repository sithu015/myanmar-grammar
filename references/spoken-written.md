# စကားပြောနှင့် စာအရေး

လုပ်ဆောင်ချက် တူသည်။ စာလုံးပုံသာ ကွဲသည်။ တစ်ခုကို တစ်ခုသို့ မပြင်နှင့်။ Tag လည်း မပြောင်းပါ။

| လုပ်ဆောင်ချက် | စာသုံး | အပြော |
| --- | --- | --- |
| ကြိယာအဆုံး၊ အမှန် | သည်၊ ၏ | တယ်၊ ရဲ့ |
| နောက်ဖြစ်မည် | မည်၊ အံ့ | မယ် |
| နာမ်ဆက် | သော၊ သည့်၊ မည့် | တဲ့၊ မယ့် |
| ကတ္တား | သည် | က၊ မှာ၊ သို့မဟုတ် ချန်ထား |
| နေရာ | ၌၊ တွင်၊ ဝယ် | မှာ |
| ပိုင်ဆိုင် | ၏ | ရဲ့။ သူ့၊ ငါ့ လို အောက်မြစ်သံသည် ပုဒ်တစ်လုံးတည်း |
| နှင့်၊ ဖြင့် | နှင့်၊ ဖြင့် | နဲ့ |
| အများ | များ၊ တို့ | တွေ |
| တားမြစ် | မ … လင့် | မ … နဲ့ |
| အကြောင်း | ကြောင့်၊ ဖြင့် | မို့ |
| ပေးခံ | အား | ကို၊ ဖို့ |
| ရှေးရှု | သို့ | ကို၊ သို့မဟုတ် ချန်ထား |
| ငါ | ကျွန်တော်၊ ကျွန်မ | ငါ၊ ကျုပ် |
| ဒီအရာ | ဤ | ဒါ။ နာမ်ရှေ့က ဒီ သည် နာမဝိသေသန |

အပြောတွင် `သည်` `ကို` `သို့` မပါတတ်ပါ။ မထည့်ပါနှင့်။ ရှေ့နာမ်သည် ကတ္တား၊ ကြိယာရှေ့က နာမ်သည် ကံ။ `လာခဲ့` `လုပ်ထား` `ပြောပါ` လို ဝါကျသည် `တယ်` မပါဘဲ ကြိယာထောက်ပစ္စည်းနှင့်ပဲ ပြီးသည်။

`။` မရှိလျှင် ဝါကျအဆုံးကို `တယ်` `မယ်` `ဘူး` မှာ ရှာပါ။ သတင်းစာထဲက အပြောကို စာသုံးသို့ မပြင်ပါနှင့်။
