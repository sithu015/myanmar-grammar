# သုဒ္ဓ၊ ကာရိုက်၊ ပစ္စည်း၊ ဝိဘတ်

Tag does not change. `ပွင့်` and `ဖွင့်` are both `v`. What changes is who does it.

| | သုဒ္ဓ | ကာရိုက် |
| --- | --- | --- |
| အနက် | ကိုယ်တိုင် ဖြစ်သည် | သူတစ်ပါးကို ဖြစ်စေသည် |
| ကာရက | ကတ္တား တစ်ခု | ကတ္တား အသစ် တစ်ခု တိုးသည်။ မူလကတ္တားသည် `ကို` နှင့် ကံ ဖြစ်သွားသည် |
| ဥပမာ | `တံခါး သည် ပွင့် တယ်` | `စုစု က တံခါး ကို ဖွင့် တယ်` |

ဖွဲ့ပုံ သုံးမျိုး။ အသံပြောင်း (`က→ခ`, `ပ→ဖ`, `မ→မှ`)၊ စာလုံးလဲ (`စား/ကျွေး`)၊ ဝါကျထဲက `စေ` `ခိုင်း` သို့မဟုတ် `အောင် လုပ်`။ အသံပြောင်းအတွဲကို `scripts/verb_pair.py` မှာ ရှာပါ။ စာလုံးပေါင်းအမှားလို မပြင်ပါနှင့်။ `လိမ့်` သည် ကြိယာနောက်တွင် လိုက်လျှင် အနာဂတ်ပစ္စည်း ဖြစ်သည်။ လှိမ့်၏ အတွဲ မဟုတ်ပါ။

`စေ` သည် ခွင့်ပြုသည်။ ပြီးမပြီး မပြောပါ။ `အောင် လုပ်` သည် ပြီးအောင် လုပ်သည်။

ပစ္စည်းသည် အတွင်း။ ဝိဘတ်သည် အပြင်။

`မ + ကြိယာ + စေ/ခိုင်း + နေ/နိုင်/ချင် + ပါ + သည်/တယ်`

`ကျောင်းသား များ သည်` သာ ရသည်။ `ကျောင်းသား သည် များ` မရပါ။ `သာ` `လည်း` `ပင်` `တော့` သာ ဝိဘတ်နောက်သို့ လိုက်နိုင်သည်။

`သည်` နာမ်နောက်တွင် `ppm`။ ကြိယာနောက်တွင် `part`။ ကြိယာဝိဘတ်ဟု ခေါ်သော စာသုံးအဆုံးသတ်ကို myPOS တွင် `part` ဟု ထားသည်။ `မသွားနှင့်` ကိုလည်း `part` ဟု ထားသည်။
